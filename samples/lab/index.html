Each character reads the same two lines (in order) with several voices. The dashed card is the voice the app uses now. “Directed” voices were given a description of the character (age, mood, accent) to act from. Pick your favourite per character and send the tags (e.g. sota-C, hana-B). Gemini voices act a little differently each time, so the same pick can sound slightly different line to line.
